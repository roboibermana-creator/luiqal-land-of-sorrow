Land of Sorrow - UI Asset Export
=================================

/background/
  assets_bg_castle_balcony.png - the clean castle balcony scene (no UI on top)

/icons_transparent/
  Picture frames + logo, cropped and with the beige grid backdrop removed
  (transparent PNG, RGBA). Best for dropping directly onto any HTML background.

/ui_elements/
  Buttons, bars, and icon panels that already have their own dark background
  as part of the design (photobooth/photo random/photo romance/calibration
  buttons, top bar, bottom instruction bar, dice/horse icons, inventory
  grid panel, photo stack icon). Left un-keyed since removing their dark
  panel would destroy the button design.

NOTE: The source you uploaded is a flattened preview screenshot, not a
layered PSD/Figma export - so these PNGs were produced by cropping +
color-based background removal rather than pulled from real transparent
layers. Edges may show minor pixel artifacts on some items (especially
the "LAND OF SORROW" logo, which has fine curling flourishes). If you
have the original layered source file, re-exporting from that will give
cleaner edges.

All assets are PNG (raster/pixel art) - not converted to SVG, since these
are hand-painted pixel-art sprites, not vector shapes; vectorizing them
would blur the pixel-art look. PNG is the correct format to insert into HTML.
