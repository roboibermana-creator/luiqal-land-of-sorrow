PAGE PHOTORANDOM — ASSET TERPISAH
=====================================

Folder:
- background/         : background arsitektur + elemen dekoratif
- ui/                 : panel, tombol, dan komponen UI
- icons/              : ikon individual
- documents/          : gulungan dokumen, wax seal, pena, inkpot
- portraits_gallery/  : portrait slots, frame, gallery assets

Semua aset disimpan sebagai PNG RGBA.
Checkerboard pada lembar sumber diperlakukan sebagai background transparan
untuk aset individual. Background arsitektur utama dipertahankan sebagai gambar penuh.

Nama ZIP: page_photorandom.zip
