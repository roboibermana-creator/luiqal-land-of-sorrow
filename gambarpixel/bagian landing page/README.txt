OUR ADVENTURE — separated PNG assets

Folders:
- background/ : clean background scene
- icons/      : individual decorative/game assets with transparent background
- ui_text/    : optional title/UI text assets

Recommended HTML:
<img src="background/background_scene.png">
<img src="icons/garden_arch.png">
<img src="icons/couple_prince_princess.png">

All icon PNGs are RGBA with checkerboard pixels removed.
Source artwork is pixel-art, so PNG is preferred over automatic SVG tracing
to avoid changing the pixel character.
